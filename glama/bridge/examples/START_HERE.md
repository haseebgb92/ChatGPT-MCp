# MCP Bridge on Glama: read-only example edition

This hosted MCP server demonstrates the real Local Files MCP protocol on **public, bundled sample documents only**.

It exposes five read-only tools: list_roots, list_files, file_info, read_file, and search_files. Its sole approved root is named public_examples.

**This server does NOT connect to your PC.** It cannot see personal documents, control Chrome, access OpenAI tunnels, write files, or execute terminal commands.

Install the actual desktop MCP Bridge from https://github.com/haseebgb92/ChatGPT-MCp to connect to authorized local resources.

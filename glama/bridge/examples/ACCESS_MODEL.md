# MCP Bridge: local-first access

* Full desktop MCP Bridge runs locally against explicitly approved folders.
* Reads are permitted for approved roots; writing and shell access are separate opt-in controls.
* Shell execution is not an operating system sandbox and requires the user's authorization.
* Local Chrome and tunnel integrations are **not** available in this hosted edition.
* This hosted edition contains only these public examples, no user files or secrets.

Do not upload private files, cookies, OAuth tokens, or tunnel secrets to this demonstration server.
